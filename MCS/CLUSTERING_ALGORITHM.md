# MCS控制器聚类算法详细说明

## 算法概述

`SelectActiveClusters` 函数实现了一维k-means聚类算法，用于将用户按照他们在**锚定MCS档位**（`m_curr`）的成功率进行分组。算法的目标是找到用户之间的自然分组，并筛选出"活跃簇"（规模足够大的簇）用于后续的MCS评分计算。

## 算法输入

- `values[]`: 一维数组，包含每个用户在锚定档位 `m_curr` 的成功率
- `n`: 用户数量
- `cfg`: 配置参数，包含：
  - `zeta`: 活跃簇占比阈值（定点数，如200表示0.2）
  - `beta`: 簇权重幂次（定点数，如1000表示1.0）
- `active`: 输出结构，包含聚类结果

## 算法流程（6个步骤）

### 步骤1：排序并保存原始索引

```c
int32_t vSorted[MCS_MAX_USERS];    // 排序后的成功率值
int idxSorted[MCS_MAX_USERS];       // 对应的原始用户索引

// 初始化
for (int i = 0; i < n; ++i) {
    vSorted[i] = values[i];        // 复制成功率值
    idxSorted[i] = i;                // 保存原始索引
}

// 插入排序（O(n²)，但n≤8，性能可接受）
for (int i = 1; i < n; ++i) {
    int32_t v = vSorted[i];
    int id = idxSorted[i];
    // 插入排序逻辑...
}
```

**目的**：
- 将用户按成功率**从小到大**排序
- 保存原始索引映射，以便后续恢复用户ID

**示例**：
```
原始: values = [0.85, 0.55, 0.92, 0.60, 0.88, 0.50, 0.75, 0.65]
      indices = [0,   1,   2,   3,   4,   5,   6,   7]

排序后: vSorted = [0.50, 0.55, 0.60, 0.65, 0.75, 0.85, 0.88, 0.92]
        idxSorted = [5,   1,   3,   7,   6,   0,   4,   2]
```

### 步骤2：计算前缀和（用于SSE计算）

在介绍前缀和计算之前，我们先详细解释**SSE（Sum of Squared Errors，平方误差和）**的概念。

#### SSE 是什么？

**SSE（Sum of Squared Errors）** 是衡量一组数据点与其平均值之间离散程度的统计量。

**数学定义**：
对于区间 `[l, r]` 内的数据点 `v[l], v[l+1], ..., v[r]`：

```
平均值：mean = (v[l] + v[l+1] + ... + v[r]) / (r-l+1)

SSE = Σ(v[i] - mean)²  其中 i ∈ [l, r]
    = (v[l] - mean)² + (v[l+1] - mean)² + ... + (v[r] - mean)²
```

**物理意义**：
- SSE衡量数据的**内聚性**：SSE越小，说明数据点越接近其平均值，簇内越紧密
- SSE越小 → 簇内数据越相似 → 聚类质量越好
- SSE越大 → 簇内数据越分散 → 聚类质量越差

**为什么用SSE进行聚类？**

在一维k-means聚类中，我们的目标是：
- 将数据分成k个簇
- 使得**每个簇内的SSE总和最小**
- 即：找到k-1个切分点，使得所有簇的SSE之和最小

**SSE的等价计算公式**：

通过数学变换，SSE可以表示为：
```
SSE = Σ(v[i] - mean)²
    = Σ(v[i]² - 2*v[i]*mean + mean²)
    = Σv[i]² - 2*mean*Σv[i] + mean²*(r-l+1)
    
由于 mean = Σv[i] / (r-l+1)，代入得：
SSE = Σv[i]² - (Σv[i])² / (r-l+1)
```

这个公式的优势是：只需要知道**Σv[i]**（一阶和）和**Σv[i]²**（二阶和），就能O(1)计算SSE！

**前缀和优化**：
```c
int64_t p1[MCS_MAX_USERS + 1];  // 一阶前缀和：Σv[i]
int64_t p2[MCS_MAX_USERS + 1];  // 二阶前缀和：Σv[i]²

p1[0] = 0;
p2[0] = 0;
for (int i = 0; i < n; ++i) {
    int64_t v = vSorted[i];
    p1[i+1] = p1[i] + v;           // 累计和
    p2[i+1] = p2[i] + v * v;       // 累计平方和
}
```

**目的**：
- 使用前缀和技巧，可以**O(1)**计算任意区间 `[l, r]` 的平方误差和（SSE）

**SSE计算公式**：
```
利用前缀和计算区间[l, r]的SSE：
- 一阶和：sum = p1[r+1] - p1[l]
- 二阶和：sum2 = p2[r+1] - p2[l]
- 区间长度：len = r - l + 1

SSE(l, r) = sum2 - (sum * sum) / len
          = (p2[r+1] - p2[l]) - ((p1[r+1] - p1[l])² / (r-l+1))
```

**示例**（n=8）：
```
i:     0    1    2    3    4    5    6    7
v:   0.50 0.55 0.60 0.65 0.75 0.85 0.88 0.92
p1:  0.00 0.50 1.05 1.65 2.30 3.05 3.90 4.78 5.70
p2:  0.00 0.25 0.55 0.91 1.33 1.97 2.81 3.58 4.50

计算区间[0, 3]的SSE：
- 数据点：v[0..3] = [0.50, 0.55, 0.60, 0.65]
- 平均值：mean = (0.50+0.55+0.60+0.65)/4 = 0.575
- 直接计算SSE：
  SSE = (0.50-0.575)² + (0.55-0.575)² + (0.60-0.575)² + (0.65-0.575)²
      = 0.005625 + 0.000625 + 0.000625 + 0.005625
      = 0.0125

- 使用前缀和计算：
  sum = p1[4] - p1[0] = 2.30 - 0 = 2.30
  sum2 = p2[4] - p2[0] = 1.33 - 0 = 1.33
  len = 4
  SSE = 1.33 - (2.30)² / 4 = 1.33 - 1.3225 = 0.0075
  
（注意：由于定点数精度，结果略有差异，但原理相同）
```

**SSE在聚类中的作用**：

当我们尝试不同的切分方案时：
- **k=2切分**：尝试所有可能的1个切分点 `s`
  - 簇1：`[0..s-1]`，SSE1 = SSE(0, s-1)
  - 簇2：`[s..n-1]`，SSE2 = SSE(s, n-1)
  - 总SSE = SSE1 + SSE2
  - **选择总SSE最小的切分点**

- **k=3切分**：尝试所有可能的2个切分点 `s, t`
  - 簇1：`[0..s-1]`，SSE1 = SSE(0, s-1)
  - 簇2：`[s..t-1]`，SSE2 = SSE(s, t-1)
  - 簇3：`[t..n-1]`，SSE3 = SSE(t, n-1)
  - 总SSE = SSE1 + SSE2 + SSE3
  - **选择总SSE最小的切分点组合**

**为什么SSE能衡量聚类质量？**

假设我们有两个切分方案：
- **方案A**：SSE总和 = 0.01（簇内数据很紧密）
- **方案B**：SSE总和 = 0.05（簇内数据较分散）

方案A更好，因为：
- 簇内用户成功率更相似
- 用簇的代表成功率评估MCS更准确
- 避免了将差异很大的用户强行分在一组

### 步骤3：穷举k=2和k=3的切分方案

#### 3.1 k=2切分（1个切分点）

```c
int64_t best2 = INT64_MAX;
int best2S = -1;

for (int s = 1; s <= n-1; ++s) {
    // 切分点s：将[0..n-1]分为[0..s-1]和[s..n-1]
    int64_t cost = SSE(0, s-1) + SSE(s, n-1);
    if (cost < best2) {
        best2 = cost;
        best2S = s;  // 记录最佳切分点
    }
}
```

**含义**：
- 尝试所有可能的切分点 `s`（共 `n-1` 种）
- 计算两个簇的总SSE，选择最小的

**示例**（n=8）：
```
s=1: [0] | [1..7]      cost = SSE(0,0) + SSE(1,7)
s=2: [0,1] | [2..7]    cost = SSE(0,1) + SSE(2,7)
s=3: [0,1,2] | [3..7]  cost = SSE(0,2) + SSE(3,7)
...
s=7: [0..6] | [7]      cost = SSE(0,6) + SSE(7,7)
```

#### 3.2 k=3切分（2个切分点）

```c
int64_t best3 = INT64_MAX;
int best3S = -1, best3T = -1;

if (n >= 3) {
    for (int s = 1; s <= n-2; ++s) {
        for (int t = s+1; t <= n-1; ++t) {
            // 切分点s和t：分为[0..s-1], [s..t-1], [t..n-1]
            int64_t cost = SSE(0, s-1) + SSE(s, t-1) + SSE(t, n-1);
            if (cost < best3) {
                best3 = cost;
                best3S = s;
                best3T = t;
            }
        }
    }
}
```

**含义**：
- 尝试所有可能的两个切分点组合（共 `C(n-1, 2)` 种）
- 计算三个簇的总SSE，选择最小的

**复杂度**：
- k=2: O(n) 次SSE计算
- k=3: O(n²) 次SSE计算
- 对于 n=8，k=3需要计算 7×6/2 = 21 次

### 步骤4：选择k值（2或3）

```c
int useK = 2;  // 默认使用k=2

if (best3 < best2) {
    // 计算相对改进率
    // improve = (best2 - best3) / best2 >= 0.10
    if ((best2 - best3) * 10 >= best2) {
        useK = 3;  // 只有当改进≥10%时才使用k=3
    }
}
```

**决策逻辑**：
- **优先使用k=2**（更简单，更稳定）
- 只有当k=3的SSE**显著降低**（相对改进≥10%）时才使用k=3
- 这避免了过度复杂化，防止小簇被分割

**示例**：
```
如果 best2 = 100, best3 = 92
改进率 = (100-92)/100 = 8% < 10%
→ 使用 k=2

如果 best2 = 100, best3 = 88
改进率 = (100-88)/100 = 12% ≥ 10%
→ 使用 k=3
```

### 步骤5：生成簇并筛选活跃簇

#### 5.1 根据选择的k值生成簇

**k=2的情况**：
```c
int sizes2[2] = { best2S, n - best2S };
const int starts2[2] = { 0, best2S };

// 构建簇
for (int c = 0; c < 2; ++c) {
    // 检查簇大小是否满足zeta阈值
    if (sizes2[c] * FIXED_SCALE >= cfg->zeta * n) {
        active->sizes[idx] = sizes2[c];
        // 将排序后的索引映射回原始用户ID
        for (int i = 0; i < sizes2[c]; ++i) {
            active->members[idx][i] = idxSorted[starts2[c] + i];
        }
        idx++;
    }
}
```

**k=3的情况**：
```c
int sizes3[3] = { best3S, best3T - best3S, n - best3T };
const int starts3[3] = { 0, best3S, best3T };

// 类似处理...
```

#### 5.2 ζ阈值过滤

**目的**：只保留规模占比≥ζ的簇作为"活跃簇"

**公式**：
```
size(c) / n >= ζ
即：size(c) * FIXED_SCALE >= ζ * n
```

**示例**（n=8, ζ=0.2）：
```
k=2切分: sizes = [3, 5]
检查: 3 * 1000 >= 200 * 8? → 3000 >= 1600 ✓ (保留)
检查: 5 * 1000 >= 200 * 8? → 5000 >= 1600 ✓ (保留)

k=3切分: sizes = [2, 3, 3]
检查: 2 * 1000 >= 200 * 8? → 2000 >= 1600 ✓ (保留)
检查: 3 * 1000 >= 200 * 8? → 3000 >= 1600 ✓ (保留)
检查: 3 * 1000 >= 200 * 8? → 3000 >= 1600 ✓ (保留)
```

#### 5.3 保底机制

```c
if (idx == 0) {
    // 如果没有簇满足阈值，选择最大的簇
    int cmax = sizes2[0] >= sizes2[1] ? 0 : 1;
    active->sizes[0] = sizes2[cmax];
    // ...复制成员...
    idx = 1;
}
```

**目的**：确保至少有一个活跃簇，避免算法失效

### 步骤6：计算簇权重

```c
int64_t weightSum = 0;

// 计算每个簇的权重（与簇大小成幂次关系）
for (int c = 0; c < active->clusters; ++c) {
    int32_t sizeFixed = active->sizes[c] * FIXED_SCALE;
    // w = size^beta（beta通常为1.0，即线性）
    int32_t w = cfg->beta == 1000 ? active->sizes[c] : FixedPow(sizeFixed, cfg->beta);
    active->weights[c] = w;
    weightSum += w;
}

// 归一化：使权重总和为1.0
for (int c = 0; c < active->clusters; ++c) {
    active->weights[c] = (int32_t)(((int64_t)active->weights[c] * FIXED_SCALE) / weightSum);
}
```

**权重公式**：
```
w_c ∝ |c|^β

其中：
- |c| 是簇c的大小（用户数）
- β 是幂次参数（通常为1.0，即线性权重）
- 最后归一化：Σw_c = 1.0
```

**示例**（β=1.0，即线性）：
```
簇大小: [3, 5]
原始权重: [3, 5]
归一化: [3/8, 5/8] = [0.375, 0.625]
```

**β的意义**：
- β = 1.0：线性权重，大簇权重更大
- β < 1.0：亚线性，减小大簇优势
- β > 1.0：超线性，增强大簇优势

```
vSorted:  [0.50, 0.55, 0.60, 0.65, 0.75, 0.85, 0.88, 0.92]
```

```
p1: [0, 0.50, 1.05, 1.65, 2.30, 3.05, 3.90, 4.78, 5.70]
```

```
k=2最佳切分点: s=4
```

## 算法特点

### 优点
1. **一维聚类**：针对单一维度（成功率），算法简单高效
2. **SSE优化**：使用前缀和技巧，O(1)计算区间SSE
3. **自适应k值**：根据数据分布自动选择2或3簇
4. **离群过滤**：通过ζ阈值过滤小簇，避免离群用户影响
5. **保底机制**：确保至少有一个活跃簇

### 时间复杂度
- 排序：O(n²)（插入排序，n≤8）
- k=2穷举：O(n)
- k=3穷举：O(n²)
- **总复杂度**：O(n²)，对于n=8，实际执行很快

### 空间复杂度
- O(n) 临时数组
- 输出：O(n) 簇成员数组

## 在MCS选择中的应用

聚类完成后，每个簇的**代表成功率**计算方式：

```c
S_c[m] = 0.7 * Q80({s[i,m] | i ∈ c}) + 0.3 * mean({s[i,m] | i ∈ c})
```

其中：
- `Q80`：80%分位数（稳健统计量，抗离群）
- `mean`：平均值
- 加权组合：70%分位数 + 30%均值，兼顾稳健性和代表性

然后用于MCS评分：
```
Score[m] = R[m] * Σ(w_c * S_c[m]^γ)
```

这样可以：
1. **忽略离群用户**：小簇被过滤，不参与评分
2. **加权聚合**：大簇权重更大，更符合组播场景
3. **稳健估计**：使用分位数而非均值，抗噪声
